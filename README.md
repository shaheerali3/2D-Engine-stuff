# 2D Engine Stuff
Experimentation with 2D systems — a collection of small C projects exploring low-level rendering, game loops, and level editing.

## 🧩 Projects
Currently includes:
- **2D Level Editor** (built using C and [Raylib](https://www.raylib.com/))

## 🕹️ Level Editor 
- **Press SPACE** — to start or enter the level editor mode
- **Enter** — move the camera around

## ▶️ How to Run
You don’t need to build it — a **precompiled executable (`game.exe`)** is already included!

1. Open the **`code`** folder.  
2. Run **`game.exe`** to launch the editor.  
3. **Press SPACE** to start the level editor mode.  

## ⚙️ Building from Source (Optional)
If you want to rebuild the project yourself, you’ll need **Raylib** installed.

### Install Raylib
Follow the official guide:  
👉 https://github.com/raysan5/raylib#building-raylib
